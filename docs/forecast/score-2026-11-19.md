# Forecast score — board of 2026-11-19 WAT, actuals from FR24

Scored on 2026-11-20 and re-run on 2026-11-22. The frozen board (`docs/forecast/board-2026-11-19.md`, commit `05e7484`) is unchanged; this file is the scoring record.

## Protocol

- Ground truth: FR24 airport departures pages for the day, fetched from a browser session to the API used by the web map (`api.flightradar24.com/common/v1/airport.json`, `mode=departures`, anchor 1795129140 = 2026-11-19 23:59 WAT), page `-1` and `-2`. One page set per board origin.
- Join: `flt|orig|dest`, one-to-one nearest by `|real schedule - board schedule|`, window `[sched-6h, sched+12h]`. Never keyed on minute-of-day alone.
- Scored leg: matched and FR24 reports a `time.real.departure`. The `actuals-2026-11-19.csv` file next to this one carries the joined ground truth (393 rows) so the score can be recomputed without the raw pages, which are gitignored under `data/`.
- Error: `real departure - predicted p50`, minutes. Coverage: actual inside the published p10-p90 window.

Reproduce:

```
node server/scripts/score-board.mjs docs/forecast/board-2026-11-19.md 2026-11-19 data
```

The raw pages are `data/fr24-19nov-hist-<ORIG>-p<n>.json`; they are gitignored, so re-fetch or replay the committed ground truth instead:

```
node server/scripts/score-board.mjs docs/forecast/board-2026-11-19.md 2026-11-19 --csv-in docs/forecast/actuals-2026-11-19.csv
```

## Caveats

- **Not independent of the harvest.** FR24 is the same provider family the history harvest came from, so this measures agreement with that provider, not truth. It is independent of our poller: the poller stored only 21 DEP events on 19 Nov before it stopped at 07:38 WAT, so it cannot score this day.
- **The 170 unscored legs are not model error.** 145 are FR24 `Unknown` (probably untracked), 19 `Canceled`, 6 estimated-only. Departures FR24 did not track are the likely `Unknown` group, so the scored set is biased toward flights that were tracked. Do not read 37.8 as board-wide accuracy.
- **One day.** The blend is 2.0 min worse than the delay prior on this day, with 20 pp lower coverage. That is a flag on blend interval width, not a conclusion; it needs several days.

## What it says

- On this day (223 scored legs; 145 untracked and 25 canceled/estimated dropped), the model beats the schedule by 31 min MAE (37.8 vs 69.1). One day is not a validation.
- Bias is +23 min on this day: departures ran later than predicted. Median absolute error 22.5 min, so the typical leg is close and the mean is dragged by a tail (QI552 +138, W3733 +208, QI560 +172, UN578 +135).
- On this day, blend covers 65% (109 legs, 75 min mean width) against delay-prior's 85% (114 legs, 130 min). That is a flag on blend band width for this day, not a general finding.
